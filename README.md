### Beijing Air Quality (PM2.5) Prediction ###

This project analyzes the Beijing PM2.5 Dataset to predict air pollution
levels based on meteorological factors. Using Python and Machine Learning, 
the project compares the performance of Linear Regression and Random Forest
models to determine which can better forecast particulate matter concentration.

# Features
Data Preprocessing: Handles missing values and scales features for better model performance.
Exploratory Data Analysis (EDA): Visualizes correlations between weather variables (Temperature, Dew Point, Wind Speed) and PM2.5 levels.
Comparative Modeling: Compares a simple Linear model against a complex Ensemble method (Random Forest).
Performance Evaluation: Uses RMSE, MAE, and R² scores to measure accuracy.

# Built With
Python: Core programming language.
Pandas/NumPy: Data manipulation and cleaning.
Matplotlib/Seaborn: Data visualization and trend analysis.
Scikit-Learn: Machine learning model training and evaluation.
Google Colab: Cloud-based development environment.

# Getting Started
To run this project:
   1. Open in Colab: Click the "Open in Colab" badge at the top of this file.
   2. Upload Data: Download the PRSA_data_2010.1.1-2014.12.31.csv dataset and upload it to the Colab session.
   3. Run Cells: Execute the cells in order (Ctrl + F9) to see the data visualizations and model results.
